Project Overview

An end-to-end IoT solution for real-time water level monitoring and automated pump control. I designed and built the entire system – from the hardware circuit using NodeMCU (ESP8266) and ultrasonic sensors to the Firebase real-time database backend and a custom Flutter mobile application.

The system allows users to monitor water levels from anywhere in the world through the mobile app, set thresholds for automatic pump switching, and receive instant alerts when levels reach critical points.

Key Features

  • Real-time water level display on mobile app with gauge visualisation
  • Automatic pump ON/OFF based on configurable thresholds
  • Manual override switch through the mobile app from anywhere
  • Push notifications when water level is critically low or full
  • Historical data logging for trend analysis
  • Low-power design for continuous 24/7 operation
