Project Overview

A comprehensive Hospital Queue Management System designed to modernize and streamline hospital operations. The system automates patient registration, intelligent doctor assignment based on specialization and availability, and real-time queue management — dramatically reducing patient wait times and improving hospital throughput.

Built with a Python Flask + FastAPI backend, MySQL database, and a clean responsive web frontend, the system provides real-time queue updates, priority handling for emergency cases, and a management dashboard for hospital administrators.

System Modules

Patient Registration

Quick patient intake with symptom tagging and urgency classification

Doctor Assignment

Intelligent auto-assignment based on specialization, workload, and availability

Queue Management

Real-time FIFO + priority queue with display boards for patients

Admin Dashboard

Analytics for average wait time, doctor utilization, and daily stats

Key Features

  • Automated patient intake and queue number generation
  • AI-assisted doctor-patient matching by specialization
  • Emergency priority escalation bypassing normal queue
  • Real-time waiting room display board for patient status
  • Multi-doctor, multi-department support
  • Admin analytics: wait times, throughput, doctor stats
