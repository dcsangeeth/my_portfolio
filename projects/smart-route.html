Project Overview

A web-based route optimization system that leverages Dijkstra's shortest path algorithm integrated with Google Maps API to compute the fastest and most fuel-efficient travel routes between multiple stops. Built with a Python Flask backend and an interactive map-based frontend.

The system is ideal for delivery services, tour planners, and travelers who need to visit multiple locations in the most efficient order — minimizing both travel time and fuel consumption.

How It Works

1. Input Stops

User enters multiple locations using the interactive Google Maps interface

2. Graph Build

Backend builds a weighted graph from the distance/time matrix via Maps API

3. Dijkstra's Algorithm

Modified Dijkstra finds the globally optimal multi-stop route order

4. Visual Route

Optimized route rendered on the map with turn-by-turn breakdown
