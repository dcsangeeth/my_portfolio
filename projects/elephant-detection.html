🐘 Geophone-Based Elephant Detection System

Seismic Sensing for Non-Invasive Human-Elephant Conflict Mitigation

Project Overview

Human-Elephant Conflict (HEC) is an escalating challenge in Sri Lanka, where expanding human settlements increasingly overlap with elephant habitats, causing human casualties, crop damage, and elephant mortality. Existing mitigation methods such as GPS collars, electric fencing, and vision-based monitoring are costly, invasive, or unreliable in dense vegetation and low-visibility conditions.

This graduation project proposes a geophone-based seismic sensing system that detects and classifies elephants by capturing the low-frequency ground vibrations generated by their footsteps. Because these seismic signals propagate through the ground and don't require line-of-sight, the system can operate reliably in dense vegetation and adverse weather, offering a non-invasive, long-range early warning capability for HEC-prone communities.

How It Works

1. Seismic Sensing

Three SM-24 geophones in a triangular layout capture ground-borne vibrations from elephant footfalls (~24 Hz)

2. Signal Conditioning

A multi-stage analog front-end amplifies and bandpass-filters the weak geophone signal (10-150 Hz) before ADC sampling

3. Feature Extraction

Time-domain and frequency-domain features (zero crossings, spectral content, DTW alignment cost, etc.) are extracted from labeled events

4. Classification

Embedded ML models (SVM, decision tree, lightweight ANN) running on the ESP32-S3 distinguish elephant footsteps from other seismic events

Key Features

  • Non-invasive, long-range detection using ground-propagating seismic (Rayleigh) waves — no line-of-sight required
  • Triangular three-geophone array enabling directional (TDOA-based) estimation
  • Custom multi-stage analog amplification and filtering circuit tuned to the 10-150 Hz elephant footfall band
  • Embedded machine learning classification on the resource-constrained ESP32-S3 platform
  • Soil moisture monitoring to study ground condition effects on seismic signal propagation
  • Real-time seismic waveform visualization and CSV-based dataset recording for field data collection
  • RTC-based time-stamping of detected events for temporal analysis and synchronized logging
