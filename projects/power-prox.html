Project Overview

PowerProx is a web-based asset management system developed at Sri Lanka Telecom's Digital Platform division. It is designed to track and maintain critical network infrastructure assets including Rectifiers, Generators, Batteries, SPDs, and UPS systems across all SLT sites island-wide.

As a Software Engineering Intern, I contributed to full-stack development, implementing new features using Flutter and Dart, ensuring seamless API integrations, and participating in agile development cycles and team code reviews to enhance code quality.
