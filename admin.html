 How to use

1. Navigate sections using the sidebar to manage Projects, Experience, Certifications, Skills, and Education.

2. Add / Edit / Delete items using the buttons in each section table.

3. Data storage: All changes are saved in localStorage. The portfolio reads this data automatically.

4. Note: localStorage is browser-specific. Export / backup is not yet implemented.
